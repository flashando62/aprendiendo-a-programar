# git-02 · Tu diario de aprendizaje 📓

**Rama:** `git-02`

## Objetivo
Acostumbrarte a hacer **varios commits chicos** con buenos mensajes, y usar `git log` y `git diff`.

## Consigna

1. Creá la rama `git-02`.
2. Creá el archivo `solucion/diario.md` con este formato:

```markdown
# Mi diario de aprendizaje

## [fecha de hoy]
- Hoy aprendí:
- Lo que más me costó:
- Una pregunta que me quedó:
```

3. Hacé **commit**.
4. Agregá una segunda entrada (puede ser de otro día o inventada) y hacé **otro commit**.
5. Agregá una tercera entrada y **otro commit**. Antes de hacer `git add`, corré `git diff` para ver qué cambió.
6. Corré `git log --oneline` y **copiá lo que sale** en la descripción del Pull Request.
7. Push y Pull Request.

## Para pensar 🤔
Escribí la respuesta en la descripción del PR:
- ¿Qué diferencia hay entre guardar el archivo (`Ctrl + S`) y hacer un commit?
- ¿Para qué sirve `git add` si después igual hacés `git commit`?

## ✅ Terminaste cuando...
- [ ] Tu PR tiene **al menos 3 commits** con mensajes claros
- [ ] Respondiste las preguntas en la descripción del PR
- [ ] Está *merged*

> 💡 **Te propongo un hábito:** seguí usando este diario todo el curso. Cada vez que termines
> un ejercicio, agregá una entrada en esa misma rama del ejercicio. En unos meses vas a poder
> leer cómo fuiste avanzando.
