# 09 · Glosario 📖

Palabras que vas a escuchar todo el tiempo. Volvé acá cada vez que aparezca una que no conocés.
**Usá `Ctrl + F` para buscar.**

---

### General

| Palabra | Qué significa |
|---|---|
| **Algoritmo** | Lista ordenada de pasos para resolver un problema. Una receta. |
| **Bug** | Un error en el programa. |
| **Código (fuente)** | El texto con instrucciones que escribís en un lenguaje de programación. |
| **Debuggear / depurar** | Buscar y arreglar errores. |
| **Editor de código** | Programa para escribir código. Usamos VS Code. |
| **Extensión (de archivo)** | Lo que va después del punto en un nombre de archivo: `.html`, `.css`, `.js`. |
| **Extensión (de VS Code)** | Un agregado que le suma funciones a VS Code, como Live Server. |
| **Indentar** | Correr el código hacia la derecha para mostrar qué está adentro de qué. |
| **Lenguaje de programación** | Un "idioma" con reglas estrictas para darle instrucciones a la compu. |
| **Pseudocódigo** | Los pasos de un programa escritos en tu idioma, antes de pasarlos a código. |
| **Ruta (path)** | La dirección de un archivo, carpeta por carpeta: `img/logo.png`. |
| **Sintaxis** | Las reglas de escritura de un lenguaje. Su "ortografía". |
| **Terminal / consola** | Ventana donde le das órdenes a la compu escribiendo comandos. |
| **Texto plano** | Texto sin formato (sin negritas ni colores). El código siempre es texto plano. |

### Web

| Palabra | Qué significa |
|---|---|
| **Backend** | La parte de una aplicación que corre en el servidor (datos, usuarios, pagos). |
| **Cliente** | Quien pide información: normalmente, tu navegador. |
| **Dominio** | El nombre de un sitio: `wikipedia.org`. |
| **Frontend** | La parte que corre en el navegador y que la persona ve y toca. HTML, CSS y JS. |
| **Herramientas de desarrollo (DevTools)** | El panel que se abre con `F12` en el navegador para inspeccionar una página. |
| **Hosting** | Un servicio que guarda tu sitio en un servidor para que esté en internet. GitHub Pages es uno. |
| **localhost / 127.0.0.1** | "Esta misma compu". Lo usa Live Server. |
| **Navegador** | Programa para ver páginas web: Chrome, Firefox, Edge, Safari. |
| **Responsive** | Un diseño que se adapta a pantallas de distinto tamaño (compu, tablet, celular). |
| **Servidor** | Una compu que guarda archivos y los entrega cuando alguien los pide. |
| **URL** | La dirección completa de una página: `https://ejemplo.com/pagina.html`. |

### HTML

| Palabra | Qué significa |
|---|---|
| **Atributo** | Información extra de una etiqueta: en `<img src="foto.jpg">`, `src` es un atributo. |
| **DOM** | La representación de la página como un árbol que JavaScript puede leer y modificar. |
| **Elemento** | Una etiqueta de apertura + su contenido + la de cierre: `<p>Hola</p>`. |
| **Etiqueta (tag)** | Las palabras entre `< >` que marcan qué es cada cosa: `<p>`, `<h1>`. |
| **Semántico** | Usar la etiqueta que **describe** el contenido (`<nav>` para un menú), no una genérica. |

### CSS

| Palabra | Qué significa |
|---|---|
| **Cascada** | La regla que decide qué estilo gana cuando hay varios para el mismo elemento. |
| **Clase** | Un nombre que le ponés a elementos HTML (`class="tarjeta"`) para darles estilo con `.tarjeta`. |
| **Media query** | Una regla CSS que se aplica solo en ciertas pantallas (por ejemplo, celulares). |
| **Propiedad** | Lo que querés cambiar: `color`, `font-size`, `margin`. |
| **Regla** | Un selector + sus propiedades entre llaves: `h1 { color: red; }`. |
| **Selector** | La parte de una regla que dice **a quién** se aplica: `h1`, `.tarjeta`, `#logo`. |

### JavaScript

| Palabra | Qué significa |
|---|---|
| **Argumento** | El valor concreto que le pasás a una función al usarla: en `saludar("Ana")`, `"Ana"`. |
| **Array** | Una lista ordenada de valores: `[1, 2, 3]`. |
| **Booleano** | Un valor que solo puede ser `true` (verdadero) o `false` (falso). |
| **Bucle (loop)** | Código que se repite varias veces: `for`, `while`. |
| **Condicional** | Código que se ejecuta solo si se cumple una condición: `if`. |
| **Evento** | Algo que pasa en la página y a lo que podés reaccionar: un clic, una tecla. |
| **Función** | Un bloque de código con nombre, reutilizable. |
| **Objeto** | Un conjunto de datos con nombre: `{ nombre: "Ana", edad: 18 }`. |
| **Parámetro** | El nombre de un dato que una función espera recibir: en `function saludar(nombre)`, `nombre`. |
| **`return`** | Lo que una función **devuelve** como resultado. |
| **String** | Un texto, entre comillas: `"Hola"`. |
| **Variable** | Una "cajita" con nombre donde guardás un valor. |

### Git

| Palabra | Qué significa |
|---|---|
| **Branch (rama)** | Una línea de trabajo paralela. |
| **Clonar** | Descargar un repositorio de GitHub por primera vez. |
| **Commit** | Una "foto" guardada de tus cambios, con un mensaje. |
| **Conflicto** | Cuando dos cambios tocan la misma línea y Git no sabe con cuál quedarse. |
| **Merge** | Juntar una rama con otra. |
| **`origin`** | El nombre corto del repositorio en GitHub. |
| **Pull** | Bajar los cambios nuevos de GitHub. |
| **Pull Request (PR)** | Un pedido para juntar tu rama con `main`, que otra persona revisa. |
| **Push** | Subir tus commits a GitHub. |
| **Repositorio (repo)** | Una carpeta de proyecto con todo su historial de Git. |
