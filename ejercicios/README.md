# 🏋️ Ejercicios

Cada ejercicio tiene:
- Un **código** (ej. `html-03`) → usalo como nombre de tu rama.
- Un `README.md` con la consigna → leelo completo antes de empezar.
- Una carpeta `solucion/` → **ahí van tus archivos** (creala si no existe).

## Cómo entregar
Seguí el ciclo de la [guía 06 · Ramas y Pull Requests](../docs/git/06-ramas-y-pull-requests.md).

## Cómo ver tus páginas web
1. Abrí el archivo `.html` en VS Code.
2. Clic derecho → **Open with Live Server**.
3. Se abre en el navegador y **se actualiza sola** cada vez que guardás. ✨

(Si no tenés Live Server, también podés hacer doble clic en el `.html` desde el explorador de archivos.)
