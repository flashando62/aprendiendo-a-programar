# git-03 · Responder una revisión 💬

**Rama:** `git-03`

## Objetivo
Practicar lo que pasa **todos los días** en un trabajo de programación: alguien revisa tu código,
te pide cambios, y vos los corregís en el mismo Pull Request.

## Consigna

1. Creá la rama `git-03`.
2. Creá el archivo `solucion/mis-metas.md` con **3 metas** que tengas para este curso:

```markdown
# Mis metas

1.
2.
3.
```

3. Commit, push y Pull Request.
4. Tu mentor **te va a pedir cambios a propósito** (es parte del ejercicio 😉).
5. Leé los comentarios en la pestaña **Files changed** del PR.
6. Hacé los cambios **en la misma rama**, commit y push. Mirá cómo el PR se actualiza solo.
7. Respondé cada comentario en GitHub (ej. *"¡Listo, corregido!"*) y marcalo como **Resolve conversation**.
8. Cuando te aprueben, merge.

## ✅ Terminaste cuando...
- [ ] Tu PR tiene al menos 2 commits: el original y el de la corrección
- [ ] Respondiste y resolviste los comentarios
- [ ] Está *merged*
- [ ] Borraste la rama `git-03` en GitHub y en tu compu

---

### 🎓 Para el mentor
Pedí 1 o 2 cambios simples, por ejemplo: *"¿Podés agregar una cuarta meta?"* o
*"¿Le ponés una fecha estimada a cada meta?"*. Usá **Request changes**.
