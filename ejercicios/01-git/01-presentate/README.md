# git-01 · Presentate (tu primer Pull Request) 👋

- **Rama:** `git-01`
- 🧠 Leer antes: [Markdown](../../../docs/fundamentos/07-markdown.md)

## Objetivo
Hacer el ciclo completo por primera vez: rama → cambio → commit → push → Pull Request → merge.

## Consigna

1. Seguí los pasos de la [guía 06](../../../docs/git/06-ramas-y-pull-requests.md) usando la rama `git-01`.
2. Creá el archivo `solucion/sobre-mi.md` con este contenido (completalo con tus datos):

```markdown
# Hola, soy [tu nombre]

- 🎂 Edad:
- 📍 De dónde soy (ciudad o provincia, nada más):
- 🎧 Algo que me gusta:
- 💭 Por qué quiero aprender a programar:
- 🚀 Algo que me gustaría crear algún día:
```

3. Hacé commit y push.
4. Abrí el Pull Request con el título `git-01 · Presentate`.
5. Cuando tu mentor lo apruebe, hacé el merge vos.

> 🔒 Recordá que el repo es **público**: no pongas datos personales sensibles (ver el README principal).

> 💡 Los archivos `.md` son **Markdown**: texto con un formato simple.
> `#` es un título, `-` es un ítem de lista. GitHub los muestra lindos automáticamente.
> Mirá cómo queda tu archivo en GitHub después del push.

## ✅ Terminaste cuando...
- [ ] Tu PR está *merged* (aparece en violeta en GitHub)
- [ ] Hiciste `git switch main` y `git pull` y ves `sobre-mi.md` en tu compu
- [ ] Marcaste el ejercicio en `PROGRESO.md` (¡eso puede ir en tu próximo PR!)
