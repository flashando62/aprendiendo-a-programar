# 🏁 Proyecto final · Tu portfolio

**Rama:** `proyecto-final`

Llegó el momento de juntar **todo** lo que aprendiste y publicarlo en internet con tu propio link. 🚀

Un **portfolio** es la página donde un programador muestra quién es y qué sabe hacer.
Es lo primero que mira alguien que te quiere contratar.

## Requisitos

### Contenido
- [ ] **Inicio:** tu nombre, una frase que te describa y tu foto (o un avatar).
- [ ] **Sobre mí:** quién sos, cómo empezaste a programar, qué te gusta.
- [ ] **Habilidades:** HTML, CSS, JavaScript, Git (con íconos o barras, como quieras).
- [ ] **Proyectos:** al menos 3 tarjetas con ejercicios del curso que te enorgullezcan
      (la lista de tareas, tu página personal, etc.), con una imagen, una descripción y un enlace.
- [ ] **Contacto:** enlace a tu GitHub y un formulario o email.

### Técnico
- [ ] HTML semántico (`header`, `nav`, `main`, `section`, `footer`)
- [ ] CSS en archivo aparte, con variables de colores
- [ ] Flexbox y/o Grid
- [ ] Responsive: se ve bien en celular
- [ ] Al menos **2 funcionalidades con JavaScript**. Ideas:
  - Botón de modo oscuro (que se recuerde con `localStorage`)
  - Menú hamburguesa en el celular
  - Botón "volver arriba" que aparece al bajar
  - Filtrar proyectos por tecnología
  - Validar el formulario de contacto antes de enviar
- [ ] Sin errores en la consola
- [ ] HTML validado en https://validator.w3.org/

### Git
- [ ] Varios commits con buenos mensajes (no uno gigante al final)
- [ ] Entregado por Pull Request

## Publicarlo en internet 🌍

Cuando esté aprobado y *merged*, tu mentor activa **GitHub Pages** en el repo y tu portfolio va a estar en:

```
https://USUARIO.github.io/NOMBRE-DEL-REPO/ejercicios/05-proyecto-final/solucion/
```

Para que los enlaces a los proyectos funcionen publicados, usá **rutas relativas**
(ej. `../../04-javascript/07-proyecto-lista-de-tareas/solucion/index.html`).

> 💡 Más adelante podés crear tu propio repo llamado `TU-USUARIO.github.io` y mover el portfolio ahí:
> vas a tener la dirección `https://TU-USUARIO.github.io` ✨
